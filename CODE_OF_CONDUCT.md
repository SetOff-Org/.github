# Code of conduct

SetOff projects follow the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, assume good faith, critique code rather than people,
and keep discussion on the work.

Harassment, personal attacks, and publishing others' private information are
not tolerated in issues, pull requests, reviews or any project channel.

## Reporting

Report conduct problems privately to an organization owner through GitHub, not
in a public thread. Reports are read by the maintainers only and handled
confidentially. Maintainers may remove comments, lock threads, or block
participants who break this code, following the Covenant's enforcement
guidelines.
